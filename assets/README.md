# Media Assets

Put screenshots and short demo recordings here before they are referenced by the README.

## Screenshots

Save final PNG screenshots in `assets/screenshots/`:

- `title.png`: title menu with the game title, character, enemies, and menu.
- `gameplay.png`: active gameplay with enemies, patches, XP, HP, and level UI visible.
- `upgrade.png`: level-up choice screen.
- `game-over.png`: run summary / game over screen.

Use the default game window size. Capture only the game window, not the desktop, terminal, menu bar, or Dock.

## Demo Recording

Save raw recordings in `assets/recordings/`.

Preferred raw file:

- `demo.mov`: 8-15 seconds showing movement, enemies, XP pickup, and upgrade selection.

The final optimized GIF should be saved as:

- `assets/demo.gif`

Keep the final GIF under 5 MB if possible.
